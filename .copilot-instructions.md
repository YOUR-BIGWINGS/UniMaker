# Universe Studio - Copilot Instructions

## Project Overview

Universe Studio is a single-page application (SPA) designed as a tool for creating and managing fictional universes, whether for Role-Playing Games (RPGs) or general creative writing and fun.

## Core Features

- **Purpose**: An organized workspace to create, store, and manage universe-building notes.
- **Architecture**: A single-page website.
- **Key Components**:
  - **Notes**: A general area for writing and expanding on ideas.
  - **Timeline Events**: A system to track chronologies, history, and events within the universe.
  - **Note Blocks**: Modular, structured sections for organizing specific pieces of information seamlessly.

## Development Guidelines

- Always prioritize a modular, single-page web architecture using React, React95, and styled-components.
- Keep the user interface focused on organization and ease of note-taking.

- the website will use react 95 for the style to give it a windows 95 aesthetic. this is not optional and must be implemented in all components and pages of the website.

-this info is for the copilot to understand the project and generate code that fits the style and requirements of Universe Studio, however, do not try to impliment this all at once, instead, break it down into smaller tasks and implement them one at a time as told to.
